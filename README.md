# GNOME Shell Extension - Topbar Weather

This is a fork from [Weather O'Clock extension](https://github.com/CleoMenezesJr/weather-oclock), a simple extension for GNOME Shell 42+ that adds an icon representing the current weather condition and the current actual temperature inside the pill next to the clock.

<b>GNOME Weather is required for this extension to function.</b>

![Screenshot](img/image.png)

## Features

Besides original features (choose right or left side of the clock), this extension also adds:

- Show/hide apparent temperature (feels like)
- Show/hide temperature unit symbol (°C or °F)

## Installation

- [GNOME Extensions](https://extensions.gnome.org/extension/9123/topbar-weather/)
- Or if somehow you need to install it from source:

```bash
$ git clone https://github.com/albersonmiranda/topbar-weather
$ cd topbar-weather
$ make install
```
